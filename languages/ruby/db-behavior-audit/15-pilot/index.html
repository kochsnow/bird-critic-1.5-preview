Expanded-pilot findings

Partial correctness becomes measurable

In these 15 audited cases, task-level reward and behavior-level evidence often aligned—but the DBB matrix exposed where otherwise unsuccessful patches still repaired real database semantics.

  1. 01

    Five of seven failed tasks passed at least one DB behavior.

    Tag scoping, recurring events, memberships, domain availability, and restores all contained grounded partial correctness.

  2. 02

    A repair can cover one application path and miss its siblings.

    PR #36528 preserved one rejoin path while direct-message create and reuse paths still wrote incorrect membership state.

  3. 03

    An alternate schema can miss the required persistence contract.

    PR #620 introduced a different notification flag but omitted the audited model, table, and downstream lifecycle.

  4. 04

    Exact replay can separate patch quality from verifier quality.

    PR #36416 passed all seven DBBs after a verifier-only repair replayed the original two patch operations exactly.

  5. 05

    Environment caveats must stay separate from semantics.

    PR #37891's missing Chromium affected one browser example, while all seven DBBs and 153 non-browser examples still grounded the patch diagnosis.

Scope and limitations

Fifteen additional cases—not a Ruby-60 estimate

This cohort extends the audit program with new evidence, but its purposive selection cannot establish population-level failure rates.

Non-overlapping cohort

These 15 tasks exclude the original five pilot cases, bringing audited coverage to 20 distinct instances from Ruby-60.

Two provider cohorts

Seven final trials are NVIDIA-backed and eight are Z.ai direct replacements; all use GLM-5.2 with OpenCode.

Control archive gap

Historical oracle/nop conclusions remain frozen in audit JSON, but 28 raw control directories are absent from the source branch.

Qualified F2P case

PR #37891 has valid DBB grounding and 153 executed non-browser examples; one browser example lacked Chromium.

Recommended interpretation: in these 15 behavior-level audited Ruby pilot cases, we observed both full and partial database correctness, cross-path propagation gaps, persistence-contract mismatches, and a clean separation between verifier environment caveats and patch semantics.
