Hi! BIRD-CRITIC 1.5

BIRD-CRITIC 1.5 extends the BIRD-Critic research line from SQL diagnostics to repository-level code debugging. It asks whether LLM agents can inspect, edit, and verify fixes for realistic user issues across mature software systems.

The benchmark separates two fixed evaluation editions from four independently maintained language tracks:

  • Lite: a fixed 100-instance multi-language evaluation for fast and comparable testing.
  • Full: a fixed 300-instance benchmark with preliminary results for deeper model analysis.
  • Language tracks: continuously updated Python, Node.js, Ruby, and PHP task pools.

Evaluation method

From issue to evidence.

Every score is backed by an executable repair, not a textual judgment. Agents work in isolated environments and succeed only when the verifier confirms the behavior.

  1. 01

    Source real repairs

    Instances are grounded in real pull requests from actively used open-source projects.

  2. 02

    Rebuild the environment

    Each task ships with a reproducible container, repository state, and dependency context.

  3. 03

    Let agents work

    Agents inspect the codebase, edit files, and run tools under a consistent protocol.

  4. 04

    Verify the repair

    Task-specific tests determine success with a clear binary reward.
